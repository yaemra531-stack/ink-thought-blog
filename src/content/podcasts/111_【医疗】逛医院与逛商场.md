# 111　【医疗】逛医院与逛商场

> 出自《孙宇晨访谈逐字稿合集（001–155）》

大家好，我是陪我APP创始人孙宇晨。我想邀你一起与我踏上财富自由革命之路，我在财富自由的另一边等着你。

现在还有一种情况就是说人工智能以后，我们的这个机器人能不能代替医生做出精准的判断和诊断呢？我个人认为人工智能会对医学有贡献，现但是现阶段颠覆医学可能还要有很漫长的路要走，这是为什么呢？就是因为真正科班出身的医生的判断水平，他很多地方还是比较小头的。就跟那个案情、律师很多对问题的判断是一样的，某种程度上是千变万化的。不是说你今天说我想怎么做这个判断就完全能按照你的判断的思路走的。但是现在非常火的这个互联网人工智能医学，可以在一个地方对医学做出非常大的贡献，就是医疗的普及以及诊断的普及。

比如说我们国家很多贫困地区，可能医生的素质根本无法经过我们刚才说的那种八年的培养。很多都是赤脚医生迅速上岗。可能赤脚医生对这个事情的了解，甚至有的还没有的患者多。在这样的地方，他们的能力应该叫会比标准化的人工工智能差。

或者至少标准化的人工智能能够给予这些赤脚医生以参考，我们不敢说完全替代的这些医生，但是可以对这些医生的诊断进行一个参考。比如说医生把一些症状输入进去之后，人工智能说可以自动判断出85%是这种可能，50%这种可能，10%是这种可能，然后由医生自己去排查。

因此我个人比较喜欢类似于像和睦家这种医院的收费模式。

它一方面就把医疗为什么贵的道理跟你讲的很清楚。比方说如果你去和睦家治疗感冒花了2000块。但实际上可能包括后来何沐家也出来说明，其实说周亚辉可能说的那夸张。何睦佳治疗感冒了可能一千多块，并不是2000元。但是和睦家会把这1000元讲的道理讲的很清楚。比如说这1000元中的900元，都是花在医生诊断你的病情，并且给出有效的治疗方案，最后剩下的50到100块钱才是治疗本身的费用，就比如说药钱或者什么之类的。

但是很多中国老百姓的定式思维，他并不是这样想问题的。他们往往认为前者的花费，也就是医生做出经验诊断的花费应该是0，后者的花费比如50块钱或者十块钱勉强可以接受。在他们的潜意识里，自己看病应该掏的就是做检查的费用和药费。

如果他最后掏的钱不多，当场还做了很多检查，回去还拿了很多的药，他就感觉自己赚到了，占了医院的便宜，甚至好几天心情都是美滋滋的。冯就说我遇到好医生了，这医生尽心尽力，但如果他花了不少钱，但是没做检查，甚至没拿到什么药，他就会觉得自己被医院坑了。其实这种心态蛮普遍的。

从这个角度上来说，我们开玩笑就说我们经常把看医生当成了购物。感觉在医院待的越久，开的药越多就越成功，就是一次成功或者优质的医疗体验，并不把解决问题治好病摆在第一位。

这感觉就好像破案时，一个老警察扫了一眼凶杀案现场，马上锁定凶手并抓捕。结果旁边的人都觉得这个老警察水平怎么这么差呢？怎么干了一天就收工了，真是太浪费了。而另外一个警察在现场，比如说待了两周做了密切的排查，然后哪怕最后抓了个错的人，旁人也会觉得这个警察认真负责，办起案来夜以继日，饭都顾不上吃，不像前面这个老警察怎么这么容易呢？感觉不像真的。

所以这就是典型的一种错误的定式思维模式。我们会发现其实衡量医生能力的标准恰恰与这种思维方式相反。医生如果能用经验凭直觉把问题很快的解决，不需要做多的检查，不需要吃多的药，恰恰是你应当为他付费的地方。

所以其实我在生活中也经常碰到这样的现象，绝大多数人是没有这样的意识，反而以开药多少评判医生或者我这次就医体验是否实惠，也不叫成功实惠。大家听这个词用的其实就已经有点可能有点用偏了。药开的多就是好，开的少就不好，最终就把医院当成了super mall去购物，是一种购物体验。

这可能就是一种典型的对治病的误区。
